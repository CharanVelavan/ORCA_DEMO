# Showcase documentation

The [public showcase](https://orca-ntn.vercel.app) provides learning and recorded playback only.
It connects no AI model, live simulator or RAG service. All network links are emulated.

- [Project README](../README.md): showcase scope and development commands.
- [Website guide](../guide.md): scenario selection and the dashboard journey.
- [Verification record](VERIFICATION.md): tested behavior and evidence limits.
- [Showcase checklist](SHOWCASE_CHECKLIST.md): delivery checks.
- [Media refresh record](MEDIA_REFRESH.md): README image and animation provenance.
- [Recording provenance](../public/data/provenance.json): source commits and bundled evidence checksums.

For installation, live endpoints, published models, RAG and performance evaluation, use the
[full ORCA-NTN repository](https://github.com/CharanVelavan/ORCA) and its judge reproducibility guide.
